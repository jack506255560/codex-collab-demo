# Codex Collab Demo

这是一个独立于业务代码的团队协作演示仓库，用最小的 Shell 程序和测试验证任务接收、隔离开发、结果交接与人工审核流程。

本仓库提供被协作修改的示例代码；协作工具、机器人适配器和 MCP 实现由独立的 [codex-collab 工具仓库](https://github.com/jack506255560/codex-collab) 维护。

## 快速运行

在仓库根目录执行以下命令即可使用示例，不需要安装应用依赖。

```sh
# 默认问候
sh greet.sh
# 输出：hello, world

# 指定姓名
sh greet.sh Alice
# 输出：hello, Alice

# 运行现有测试
sh test.sh
# 输出：base checks passed
```

运行环境需要 Git 和兼容 POSIX 的 Shell；macOS、Linux 均可直接运行上述命令。

## 文件说明

| 文件或目录 | 用途 |
| --- | --- |
| `greet.sh` | 问候程序，使用第一个参数作为姓名，未传姓名时使用 `world`。 |
| `test.sh` | 验证默认问候和指定姓名的输出。 |
| `AGENTS.md` | Agent 参与本仓库协作时应遵循的规则。 |
| `.agents/skills/team-collab/SKILL.md` | 读取任务、隔离开发、交接及审核的协作说明。 |
| `.codex/config.toml.example` | MCP 连接配置示例，需要按个人环境配置。 |
| `docs/agent-collab/` | 早期 v1 协议及数据 Schema 的版本化副本。 |

桌面对话协作所用的 `team-collab-desktop` Skill 和项目 MCP 配置由接入工具安装；克隆本仓库后仍需完成个人接入配置。

## 桌面对话协作流程

已完成企业微信接入、身份配置和对话绑定的环境，可以使用 `desktop_poll` 模式：

1. 真人在已配置的企业微信群中 `@` 对应机器人，描述需求和验收条件。
2. 本机机器人适配器校验消息权限，把需求写入 Git 协作记录。
3. 已绑定的 Codex 桌面对话通过定时心跳调用 MCP，解释需求并认领任务；信息不足时先追问。
4. Agent 在任务分配的独立工作树和分支中完成当前阶段，运行检查并提交代码。
5. MCP 验证结果并推送任务分支，按团队配置产生交接或审核通知。
6. 指定真人审核结果；多阶段任务按配置交给下一位成员。审核、任务完成和代码合并是分别处理的步骤。

要持续接收任务，Codex 桌面应用、对话心跳和本机机器人适配器都需要保持可用。仅配置 MCP 或绑定对话，不会自动唤醒对话。

## 分支与提交约定

- `main` 保存示例代码、测试和说明文档。
- `agent-collab` 保存任务及协作事件记录，不应合并回 `main`。
- 代码和文档变更在任务分配的独立分支中完成，审核后再通过项目约定的流程合并。
- 交接应包含简明结果、检查证据以及准确的提交或 PR 引用。
- 密钥、个人配置、私有路径和完整聊天记录不应提交到仓库。

## 演示范围与协议说明

现有 `greet.sh` 只实现默认问候和姓名参数，`test.sh` 只覆盖这两种行为。早期演示任务 `T-001` 中的 `--upper` 是待实现功能示例；任务数据的存在不代表功能已经实现，也不代表任务已自动派发。

`docs/agent-collab/` 保留的是早期 v1 协议副本，不会随个人工具安装自动升级。实际任务状态、租约、审核规则和协作流程，应以当前安装的工具版本及 MCP 返回结果为准。接入或升级协作工具时，请查阅工具仓库的对应文档。
